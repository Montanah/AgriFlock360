# AgriFlock360 – Unified Livestock Management & IoT Brooder System

AgriFlock360 is a multi-platform agricultural technology ecosystem combining:

- Real-time IoT smart brooder hardware
- Mobile App (Flutter)
- Web Dashboard (React + TailwindCSS)
- Backend APIs (Node/Express/NestJS)
- FinTech PAYG & Lease-to-Own Management
- Farmer Analytics + Alerts + Telemetry Visualization

This repository houses all the source code for the AgriFlock360 MVP:
- Firmware  
- Hardware documentation  
- Backend  
- Mobile app  
- Web dashboard  
- Architecture documentation  

---

## 🔥 Core System Components

### 1. **IoT Smart Brooder**
- ESP32-based controller  
- Temperature + humidity sensing  
- Heater & fan automation  
- MQTT telemetry  
- Fintech PAYG lock/unlock firmware  
- Manual override system  
- Offline caching + OTA updates  

### 2. **Backend API**
- Authentication & RBAC  
- Telemetry ingestion  
- Device registry  
- PAYG/Lease-to-Own engine  
- Farmer management  
- Alerts + analytics  

### 3. **Mobile App (Flutter)**
- Farmer-facing app  
- Flock management  
- Vaccination & feeding modules  
- IoT dashboard  
- Push notifications  

### 4. **Web Admin Dashboard (React)**
- Device monitoring  
- Payment management  
- Farmer accounts  
- Telemetry charts  
- Alert center
